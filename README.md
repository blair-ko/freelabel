# FreeLabel Studio — 網頁版連續標籤設計與列印工具

[繁體中文](README.md) | [English](README.en.md)

**FreeLabel Studio** 是一個純前端、零建置步驟（Zero-Build）的網頁版連續標籤設計與列印應用程式，專為熱感應標籤機（如 GoDEX G500）與一般標籤貼紙設計，支援精準毫米（`mm`）排版、向量 SVG 圖示、多款中英文字型、文字特效、條碼/QR Code 生成與多標籤連續列印佇列。

---

## 功能特色

- **精準連續標籤列印與佇列管理**
  - 內建常用紙張規格（`40×25 mm`、`60×40 mm`、`50×30 mm`、`40×30 mm`、`80×50 mm`、`100×150 mm`、圓形 `40×40 mm`、`24mm`/`12mm` 連續色帶），亦支援自訂寬高與圓角（`mm`）。
  - 下方**連續標籤紙捲佇列**支援新增、複製、刪除與勾選複數標籤，**僅列印被選中的標籤**（也可一鍵「全選 / 僅印目前」）。
  - 支援**批次序號產生**（自動替換文字或條碼中的 `{n}` 產生連續編號標籤）。
  - 提供**列印偏移 X / Y (mm)** 微調與**熱感應黑白預覽**模式，搭配 `@media print` 零邊界分頁列印。
- **豐富的向量 SVG 圖示與條碼**
  - 內建 **34 款向量 SVG 圖示**，涵蓋五大分類：物流倉儲、零售促銷、食品烘焙、辦公收納、可愛裝飾，支援搜尋與自訂色彩。
  - 支援**匯入自訂 SVG**（貼上 SVG 程式碼或上傳 `.svg` 檔案）。
  - 內建純前端向量 **Code 128 一維條碼** 與 **QR Code** 生成器。
- **多樣化圖形樣式**
  - 支援實心矩形、圓角外框、虛線剪裁框、膠囊形、圓形/橢圓、三角形、菱形、六角形、五角星、促銷爆炸貼、橫幅彩帶、吊牌、對話氣泡與實線/虛線/波浪分隔線。
- **豐富字型、文字框與文字特效**
  - 整合 12 款中英文字型（思源黑體、思源宋體、Zen Maru Gothic 圓體、Klee One 手寫楷體、Mochiy Pop One 海報體、Inter、Playfair Display、Bebas Neue、Oswald、Pacifico、Fredoka、JetBrains Mono）。
  - 提供 8 種文字框預設（膠囊反白框、雙線印章框、虛線折價框、品名規格欄位框、弧形圓章文字等），可自訂框底色、框線色、線寬、圓角與實線/虛線/點線/雙線。
  - 提供 8 種文字特效：**無特效、粗描邊、柔和陰影、3D 硬邊、霓虹發光、雙色漸層、螢光底色、反白印章**，以及 **SVG 弧形路徑文字**。
- **直覺的畫布編輯體驗**
  - 拖曳移動（含中心對齊吸附線）、8 向縮放、自由旋轉、雙擊內文即時編輯、圖層上下調整/鎖定/隱藏、5mm 格線切換、復原/重做（`Ctrl+Z` / `Ctrl+Y`）。
  - 支援匯出 **SVG 向量檔**、**PNG 高清圖檔** 與 **JSON 專案檔**匯出/匯入，並自動儲存於瀏覽器 `localStorage`。

## 快速開始

本專案不需安裝任何套件或編譯工具，使用任一靜態網頁伺服器啟動即可：

```bash
git clone https://github.com/blair-ko/freelabel.git
cd freelabel
python3 -m http.server 8766
```

接著在瀏覽器開啟：`http://localhost:8766`

## 熱感應標籤機列印建議（以 GoDEX G500 為例）

1. 在瀏覽器列印視窗中，將**邊界**設為「**無 (None)**」、取消勾選「頁首與頁尾」，縮放保持 `100%`。
2. 標籤尺寸請輸入**自黏貼紙本體大小**（例如 `40 × 25 mm`），不需包含底紙襯邊與間距。
3. 若出現整體微幅偏移，可直接使用畫布右側面板的「**列印偏移 X / Y (mm)**」進行 `0.5 mm` 級微調。
